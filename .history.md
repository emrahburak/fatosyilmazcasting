# Proje Tarihçesi

## [17.02.2026 01:13]

### Multi-Domain (Subdomain) Mimari Kurulumu

**Kapsam:** Next.js 14+ App Router ile hostname-based routing, Cloudflare D1 & R2 entegrasyonu, DB agnostic yapı

#### Eklenen Paketler
- `prisma`, `@prisma/client`, `@prisma/adapter-d1` - ORM katmanı
- `@aws-sdk/client-s3`, `@aws-sdk/s3-request-presigner` - Cloudflare R2 entegrasyonu
- `jose` - JWT session yönetimi
- `react-hook-form`, `@hookform/resolvers`, `zod` - Form validasyonu
- `wrangler` - Cloudflare Pages/Workers development

#### Yeni Dosyalar
- `middleware.ts` - Hostname bazlı routing (fatosyilmazcasting.com → (main), panel. → (panel))
- `prisma/schema.prisma` - DB agnostic schema (SQLite/PostgreSQL destekli)
- `lib/db.ts` - Prisma client singleton (D1 adapter ile)
- `lib/s3.ts` - Cloudflare R2 client (AWS SDK v3)
- `lib/auth.ts` - RBAC & JWT session yönetimi (ADMIN, AGENT, TALENT rolleri)
- `lib/constants.ts` - Rol tanımları, proje tipleri, status değerleri
- `lib/actions/auth.actions.ts` - Login, logout, invitation-based register
- `lib/actions/talent.actions.ts` - Talent CRUD, audition yönetimi
- `lib/i18n/data.json` - TR/EN çeviri dosyası
- `lib/i18n/index.ts` - i18n helper fonksiyonları
- `wrangler.toml` - Cloudflare D1 & R2 binding yapılandırması
- `.env.example` - Environment değişkenleri şablonu

#### Route Groups
- `app/(main)/` - Ana site (public facing pages)
- `app/(panel)/` - Admin panel (private dashboard)
  - `login/page.tsx` - Login formu
  - `page.tsx` - Dashboard ana sayfa

#### Yapılandırma Değişiklikleri
- `next.config.ts` - R2 remote patterns, güvenlik headers (CSP, X-Frame-Options, vb.)
- `app/layout.tsx` - Root layout (her iki route group için ortak)

#### Özellikler
- **DB Agnostic:** SQLite (D1) → PostgreSQL geçişi sadece schema.prisma provider değişikliği ile
- **i18n Hazır:** TR/EN çoklu dil desteği (bio_tr/bio_en alanları)
- **RBAC:** Rol bazlı erişim kontrolü (ADMIN > AGENT > TALENT)
- **Invitation-Only:** Davetiye tabanlı kullanıcı onboarding
- **Server Actions:** Form işlemleri için API route yerine Server Actions

#### Notlar
- NixOS ortamında Prisma engine indirme sorunu (production Cloudflare'de çözülecek)
- Middleware ile subdomain routing aktif
- Port 3001'de çalışıyor (package.json)
